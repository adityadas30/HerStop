# Feature Planner

Use this skill before implementing any non-trivial feature.

## Goals
- Restate the feature in plain English
- Identify the user-facing outcome
- List files to create/update
- Describe data flow end to end
- Identify backend/schema impact
- Identify required env vars, API keys, and secrets
- Note analytics/error tracking implications
- Define acceptance criteria
- Call out edge cases and risks

## Required output format
1. Feature summary
2. Files to create/update
3. Data flow
4. Backend/schema impact
5. Env vars / secrets needed
6. Acceptance criteria
7. Edge cases / risks
8. Recommended implementation order

## Rules
- Prefer simple architecture
- Flag overengineering
- Keep plans beginner-readable
- If the feature conflicts with HerStop trust language, say so clearly
