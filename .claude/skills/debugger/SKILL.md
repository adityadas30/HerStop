# Debugger

Use this skill when errors, broken builds, or unexpected behavior appear.

## Debug workflow
1. Restate the symptom
2. Separate symptom from likely cause
3. List the top 2-4 likely root causes
4. Inspect relevant files and logs
5. Propose the smallest reasonable fix
6. Explain why that fix is preferred
7. Note how to verify the fix

## Rules
- Do not refactor broadly unless necessary
- Prefer reproducing before changing code
- Prefer the smallest good fix over a rewrite
- If the issue is environment/setup related, say so directly
- If uncertain, say what evidence is missing
