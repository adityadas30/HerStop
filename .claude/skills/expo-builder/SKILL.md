# Expo Builder

Use this skill when building screens, components, navigation, or app-side logic.

## HerStop engineering rules
- iOS-first
- Expo + React Native + TypeScript
- Expo Router
- Keep code beginner-readable
- Small reusable components
- Prefer supported Expo patterns
- Avoid unnecessary abstraction
- Favor clean file structure over cleverness

## UI rules
- Apple-clean
- premium
- maps-first
- subtle feminine accent is okay, but avoid making the UI childish or stereotyped

## Output expectations
Before writing code:
1. State files to create/update
2. State the implementation plan
3. Mention any packages needed

While coding:
- Use TypeScript everywhere
- Keep functions small
- Use meaningful names
- Add brief comments only where they truly help learning

After coding:
- Summarize what changed
- Mention follow-up cleanup or known limitations
