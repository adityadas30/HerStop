## Proposed changes and what remains unverified

`008_review_edit_delay.sql` and `009_caller_moderation_and_grants.sql` are **review proposals** under proposed-fixes, tested locally in a separate phase only. They use guarded definition substitutions and intentionally fail on unexpected source drift; they are not idempotent migration replacements and must not be blindly re-run. Before promotion assign final migration versions, review their visibility/API changes, add a rollback/data-retention plan for edited_at, test hosted API schema cache/ownership/default ACLs, and update the staging script's vulnerability expectations. Do not run baseline downs on a database with these proposals installed.

The public API script uses manual owner checkpoints to age/hide/ban and inspect auth.users; its MANUAL rows are attestations. It was only syntax-checked locally, not executed. The local harness is evidence of PostgreSQL semantics, not proof of SMTP/OTP, iPhone sessions/saves/directions/UI failure rollback, Supabase JWT verification, managed deletion, storage erasure, PostgREST or backup restoration. All nine live acceptance items remain founder verification work.
